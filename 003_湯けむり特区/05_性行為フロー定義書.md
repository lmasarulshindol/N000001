## 基本フロー（A系）

### A-1: 前戯のみ

**用途**: 関係初期、信頼構築段階、ソフトなシーン向け

```
【導入】雰囲気作り（200〜300字）
  └ 場所の設定（部屋・温泉・布団の上等）
  └ きっかけ（会話・ムードの高まり・誘い）

【展開1】軽いスキンシップ（400〜600字）
  └ 手を握る・頭を撫でる・抱きしめる
  └ キス（軽い→深い）
  └ 相手の反応描写

【展開2】愛撫（600〜1000字）
  └ 服の上から触る→直接触る
  └ 胸への愛撫（揉む・舐める・吸う）
  └ 下半身への愛撫（触る・擦る・指入れ）
  └ 女性側の反応（声・仕草・身体の変化）

【クロージング】余韻（300〜500字）
  └ 興奮状態のまま終わる / 抱きしめて落ち着く
  └ 「次」への期待感を残す会話
  └ 心情描写
```

**射精**: なし（勃起状態の描写のみ）  
**女性側の絶頂**: あり（軽いもの）またはなし

### A-2: 前戯＋手コキ

**用途**: オーラル抵抗ある子、序盤の行為、「してあげたい」系

```
【導入】雰囲気作り（200〜300字）
  └ 場所・状況設定
  └ 相手からのアプローチ or こちらからの誘導

【展開1】相互愛撫（600〜1000字）
  └ キス・抱擁
  └ 女性への愛撫（胸・秘所）
  └ 女性の手が男性器へ

【展開2】手コキ（1000〜1500字）
  ├ 初期: 探るような動き、恥ずかしそうな様子
  ├ 中期: リズムが安定、反応を見ながら調整
  └ 終盤: 射精の予感、女性の期待・緊張

【射精】フィニッシュ（500〜800字）
  └ 射精の瞬間（量・勢い・場所）
  └ 女性の反応（驚き・満足・恥ずかしさ）
  └ 事後処理の描写

【クロージング】余韻（300〜400字）
  └ 感想・感謝の言葉
  └ 親密度上昇の描写
```

**射精場所オプション**: 
- 手の上
- お腹・胸の上
- ティッシュ・タオルで受ける

### A-3: オーラルのみ

**用途**: 挿入前段階、口内射精シーン、相互フェラ＆クンニ

```
【導入】きっかけ（200〜400字）
  └ 自然な流れ or 「してあげたい」の申し出
  └ 体勢の移行（座る・寝る・跪く）

【展開1】クンニ（800〜1200字）※先に男性から
  ├ 開始: 秘所への接近、匂い・形状の描写
  ├ 愛撫: 舌の動き（縦・横・円）、クリへの刺激
  ├ 女性の反応: 声・腰の動き・手の位置
  └ 絶頂: 女性のイク瞬間、痙攣・脱力

【展開2】フェラ（1000〜1500字）
  ├ 開始: 手でのサイズ確認、顔の接近
  ├ 前半: 舐める（亀頭・裏筋・竿）、咥える
  ├ 後半: 出し入れ、深く咥える、リズム
  └ 射精前: 男性の予告、女性の選択（出す場所）

【射精】口内射精 or 顔射（600〜1000字）
  ├ 口内射精: 発射の瞬間、精液の量・味の反応、飲む/吐く
  └ 顔射: かかる位置、女性の表情、事後処理

【クロージング】余韻（300〜500字）
  └ 口内の場合: 飲み込む描写、感想
  └ 顔射の場合: 拭き取り、羞恥の表情
  └ 親密な会話・抱擁
```

**バリエーション**:
- 女性から先にフェラ → お返しクンニ
- 69（シックスナイン）同時愛撫
- フェラのみ（クンニなし）
- クンニのみ（フェラなし）

## 標準フロー（B系）

### B-1: 本番あり（1回）

**用途**: 基本的な性行為シーン、各話のメインシーン

```
【導入】ムード作り（300〜500字）
  └ 場所・時間帯の設定
  └ 行為に至る流れ（自然な誘い・雰囲気）
  └ 服を脱ぐ/脱がせる

【前戯】相互愛撫（1000〜1500字）
  └ キス・全身への愛撫
  └ 胸への刺激（揉む・舐める・吸う）
  └ 秘所への刺激（指・舌）
  └ 濡れ具合の確認、挿入準備

【挿入準備】（200〜400字）
  └ コンドーム装着 or 生の確認
  └ 体位の調整、先端を当てる
  └ 挿入前の緊張・期待

【本番】挿入〜射精（1500〜2500字）
  ├ 挿入の瞬間: 感触、締め付け、女性の反応
  ├ ゆっくり: 奥まで入れる、慣らし、表情確認
  ├ ピストン: リズム開始、体位の描写、声
  ├ 加速: 激しさ増す、女性の絶頂接近
  ├ 女性絶頂: イク瞬間、痙攣、締め付け
  └ 射精: 予告、発射、中/外の描写

【クロージング】余韻（500〜800字）
  └ 抜く瞬間、溢れる精液（中出しの場合）
  └ 抱き合う、感想を言い合う
  └ 次への期待、眠りに落ちる等
```

**体位オプション**:
| 体位 | 特徴 | 適したシチュ |
|------|------|-------------|
| 正常位 | 顔が見える、王道 | 初めて、愛情表現 |
| 騎乗位 | 女性主導、攻め | 積極的な子、2回目以降 |
| 後背位 | 激しい、支配的 | 興奮時、調教 |
| 側位 | ゆったり、密着 | 添い寝からの流れ |
| 座位 | 密着、抱きしめ | 親密、温泉内 |

### B-2: 本番あり（2回）

**用途**: 1話の大半を占めるメインシーン、連続射精描写

```
【1回戦】（3500〜4500字）
  └ B-1フローに準拠
  └ 1回目の射精で終了

【インターバル】休憩（500〜1000字）
  └ 会話・スキンシップ
  └ 水分補給、汗を拭く
  └ 回復の描写（男性の勃起回復）
  └ 2回戦への誘い/きっかけ

【2回戦】（3000〜4000字）
  ├ 前戯: 1回戦より短め、すぐ濡れている
  ├ 挿入: 体位を変える、1回戦と違う刺激
  ├ 本番: より激しく、遠慮がなくなる
  └ 射精: 1回目より量は少ないが濃い描写

【クロージング】疲労と満足（500〜700字）
  └ 疲れて動けない二人
  └ 「今日は○回もしちゃったね」的会話
  └ 眠りに落ちる / 風呂に入る
```

**2回戦の変化ポイント**:
- 体位を変える（正常位→騎乗位等）
- 女性がより積極的になる
- 声・反応が大きくなる
- 「もっと」「まだ足りない」等の台詞

### B-3: 本番あり（3回以上）

**用途**: 長時間プレイ、体力自慢設定、特別な夜

```
【1回戦】正統派（2500〜3500字）
  └ 丁寧な前戯から本番
  └ 正常位中心、お互いを確かめ合う

【インターバル1】（300〜500字）
  └ 「すごい…まだ元気なの？」的反応
  └ 短い休憩、すぐ再開ムード

【2回戦】変化球（2500〜3500字）
  └ 体位を変える（後背位、騎乗位等）
  └ より激しく、遠慮なく
  └ 女性が複数回イく描写

【インターバル2】（300〜500字）
  └ 「もう無理…」と言いつつ…
  └ 男性からの再アプローチ

【3回戦】クライマックス（2500〜3500字）
  └ 最も激しい、限界突破
  └ 女性が連続絶頂、泣きながらイく
  └ 大量射精、中出し推奨

【クロージング】脱力（500〜1000字）

  └ 溢れる精液、シーツの惨状

**回数増加のコツ**:
- 各回で体位・シチュを変える
- 女性の状態変化を丁寧に（余裕→必死→限界）
- 射精の変化（量・勢い・場所）
- 声の変化（控えめ→大きく→嗚咽）

## 特殊フロー（S系）

### S-1: 特殊シチュエーション

#### 拘束プレイ
```
【セットアップ】
  └ 手を縛る（リボン/ネクタイ/ロープ/手錠）
  └ 目隠しを追加するとさらに感度UP描写
  └ 「動けない」「されるがまま」の強調

【展開の特徴】
  └ 焦らしが効く（触れそうで触れない）
  └ 「やめて」が「もっと」に変わる
  └ 普段より大きな反応
```

#### 道具使用
```
【ローター/バイブ】
  └ スイッチ入れる瞬間の描写
  └ 振動による快感（波状/一定）
  └ 「機械なのに」という背徳感

【オイル/ローション】
  └ ぬるぬる感の描写
  └ 滑る→入りやすい
  └ 音がいやらしい

【コスプレ/制服】
  └ 着衣のままの行為
  └ めくる/ずらす描写
  └ 「この格好で」という羞恥
```

### S-2: 羞恥プレイ

#### 見られる系
```
【シチュエーション例】
  └ 薄い壁越しに声が漏れる
  └ 窓が開いていた
  └ 鏡の前で自分の姿を見せられる
  └ カメラで撮影される

【描写ポイント】
  └ 「見られてるかも」という不安と興奮
  └ 恥ずかしさで感度が上がる描写
  └ 声を我慢しようとして失敗
```

#### 言葉責め
```
【セリフ例】
  └ 「どんな顔してるか、言ってごらん」
  └ 「ここ、すごいことになってるよ」
