# 舞台設定：星降り温泉「湯けむりロッジ」

## 基本情報

| 項目 | 内容 |
|------|------|
| 名称 | 星降り温泉「湯けむりロッジ」 |
| 所在地 | 山梨県北部の山奥（架空の星降村） |
| アクセス | 最寄り駅からバスで40分＋徒歩15分 |
| 客室数 | 12室（定員36名） |
| 特徴 | 標高1200mの高原に位置し、天然温泉と星空が売り |

## コンセプト

「**若い感性で創る、新しい温泉体験**」

老舗旅館だった建物をリノベーションし、若いオーナーが「若者による若者のための温泉宿」として再生。
SNS映えするモダンな内装と、伝統的な温泉の良さを融合させた新感覚の宿。

## 施設概要

### 外観・建物
- **本館**: 3階建ての木造モダン建築（外壁は白とウッドブラウン）
- **露天風呂エリア**: 星空が見える開放的なデザイン
- **カフェラウンジ**: 大きなガラス窓から山々を一望
- **従業員寮**: 本館裏手の2階建て

### 内装テイスト
- 北欧×和モダンのミックススタイル
- ナチュラルウッドとホワイトを基調
- 間接照明とグリーンを多用
- Wi-Fi完備、各部屋にタブレット端末設置

### 温泉
- 泉質：単純硫黄泉（美肌の湯）
- 内湯2つ、露天風呂2つ、貸切風呂3つ
- 温泉は24時間利用可能

## オーナー情報

**白峰 美月（しらみね みづき）** 28歳・女性

- 元IT企業のマーケティング担当
- 3年前に祖母から旅館を相続し、脱サラして経営を引き継ぐ
- 「若い子たちが活躍できる場所を作りたい」という理念

- サバサバした性格だが、従業員のことを本当に大切にしている

- 10〜24歳の女性限定（オーナーの方針）
- 学生はアルバイト、成人は正社員として雇用
- 住み込み可（従業員寮完備）
- 「接客未経験OK、やる気重視」がモットー
- 全員が何らかの「夢」や「目標」を持っている子を採用
