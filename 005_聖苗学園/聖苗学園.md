## 1. 学園概要

### 基本情報

| 項目 | 詳細 |
|------|------|
| 正式名称 | 学校法人 聖苗学園（せいびょうがくえん） |
| 英名 | Seibyo Academy — Institute of Reproductive Education |
| 創立 | 203X年（「若年就労特別法」施行の翌年） |
| 所在地 | 東京都郊外（緑豊かな丘陵地帯に広大なキャンパス） |
| 学校種別 | 小中高一貫・女子校（12年制） |
| 生徒数 | 約600名（各学年50名 × 12学年） |
| 教職員数 | 約80名（うち「実習教官」30名） |
| 寮 | 全寮制（希望者は通学も可能だが95%が寮生活） |

### 学園の理念

> **「未来の命を育む、聖なる苗床となれ」**

少子化が極限まで進行した近未来日本において、「若年出産」を国策として推進する流れの中で設立された特殊教育機関。通常の学校教育に加え、**生殖に関する知識・技術・実践**を体系的に学ぶカリキュラムを提供する。

## 3. 学年制度と進級

### エスカレーター制度

聖苗学園は完全エスカレーター制。入学すれば、**試験なしで小学校→中学校→高等部**へ自動進級する。ただし、各段階で「実践」の進度に差が出るため、以下のクラス分けが行われる。

### 小学部（1〜6年生）

| 学年 | 年齢 | カリキュラム概要 |
|------|------|------------------|
| 1年 | 6-7歳 | 基礎知識（自分の体を知る） |
| 2年 | 7-8歳 | 男女の違い、赤ちゃんの作り方（理論） |
| 3年 | 8-9歳 | 技術基礎（キス・愛撫の練習。相手は女性教官） |
| 4年 | 9-10歳 | 技術応用（口での奉仕。模型→女性教官→男性教官） |
| **5年** | **10-11歳** | **【実践開始】初めての挿入実習（早熟クラスのみ）** |
| 6年 | 11-12歳 | 実践継続。妊娠準備教育（排卵管理・基礎体温） |

### 莉子先生の解説（小学5年生について）

> 「小学5年生、つまり10歳か11歳の子たちの一部が『早熟クラス』に選ばれます。
> 選ばれる基準は、第二次性徴の進み具合、本人の意欲、そして……体の準備ができているかどうか。
> 
> 早熟クラスに入った子は、5年生の夏休み明けから『実習室』に通い始めます。

> そして秋頃、一人ずつ『初めて』を迎えます。

> だから、みなさんの気持ちはよく分かりますよ。怖いのも、ドキドキするのも、全部」

### 中学部（7〜9年生）

| 学年 | 年齢 | カリキュラム概要 |

| 8年（中2） | 13-14歳 | 応用技術（複数体位、長時間持続、男性を射精に導くテクニック） |

| 11年（高2） | 16-17歳 | 妊娠・出産コース選択（希望者は在学中に出産体験） |

## 4. 早熟クラス制度

### 選抜基準

小学5年生（10〜11歳）の中から、以下の基準を満たす生徒を「早熟クラス」として選抜する。

| 基準 | 詳細 |
|------|------|
| **身体的成熟度** | 初潮の有無、乳房の発達（タナーステージII以上）、身長・体重の発育状況 |
| **心理的準備** | 本人面談での意欲確認、恐怖心の程度、好奇心の強さ |
| **保護者同意** | 入学時の包括同意に加え、早熟クラス用の追加同意書 |
| **医学的適性** | 婦人科検診で挿入に耐えうる発育を確認 |

### 莉子先生の解説

> 「早熟クラスに選ばれるのは、学年の約20%。50人中10人くらいね。
> 『選ばれなかった』って落ち込む子もいるけど、焦らなくていいの。
> 体の準備ができたら、6年生でも7年生でも、ちゃんと実習は始まるから。
> 
> 逆に、早熟クラスに選ばれたけど『まだ怖い』って子もいる。
> そういう子は無理しなくていい。見学だけ続けて、心の準備ができたら参加すればいい。
> 
> ……ただね、先生の経験から言うと。
> 最初の一回を乗り越えたら、あとは案外平気になるものよ。
> 体って、ちゃんと慣れるようにできてるの」

### 早熟クラスの初実習プロセス

```
1. 見学期間（1ヶ月）
   └ 先輩の実習を見学室から観察

2. 模擬実習
   └ 男性教官との模擬行為（挿入なし。愛撫・口での奉仕まで）

3. 初実習（本番）
   └ 個室にて、担当教官との初めての挿入
   └ 必ず女性教諭が立ち会い、サポート
   └ 記録映像を撮影（教材用）

4. フォローアップ
   └ 翌日のカウンセリング
   └ 体調確認、心理ケア
   └ 2週間後から通常実習サイクルへ
```

## 6. 妊娠・出産プログラム

### 在学中妊娠制度

聖苗学園では、**中学3年（9年生）以上の生徒**が希望すれば、在学中に妊娠・出産を経験できる。

| 項目 | 詳細 |
|------|------|
| 対象 | 9年生（14歳）以上の希望者 |
| 手続き | 本人申請 → 保護者同意 → 医学検査 → マッチング |
| 相手 | 外部教官、VIP教官、または本人指名の一般男性（審査あり） |
| 費用 | 全額学園負担（政府補助金適用） |
| 出産後 | 学園内託児施設で養育可能。学業との両立をサポート |

### 卒業制作としての出産

高等部3年（12年生）では、卒業制作として「妊娠・出産」を選択できる。

- 在学中に妊娠し、卒業式前後に出産
- 出産をもって「最高の実践成果」とみなされる
- 卒業生の約30%がこの制度を利用

### 莉子先生の解説

> 「卒業制作で出産を選ぶ子、結構いるのよ。
> 12年間、体で学んできたことの集大成として、命を産み出す。
> 
> ……先生は、まだ産んでないけど。
> いつか産みたいな、って思うことはある。
> あの人の……ううん、なんでもない。
> 
> とにかく！ 妊娠は義務じゃないから。選択肢の一つ。
> 産まなくても、この学園で学んだ技術と知識は、社会で必ず役に立つわ」

## 7. 卒業後の進路

### 主な進路

| 進路 | 割合 | 詳細 |
|------|------|------|
| **風俗業界** | 35% | BabyDoll系列店など。即戦力として高待遇で迎えられる |
| **生殖関連企業** | 25% | 精子バンク、代理母仲介、不妊治療クリニックの「相談員」等 |
| **教育機関** | 15% | 聖苗学園や類似校の教官・教諭として勤務 |
| **一般企業** | 15% | 秘書、受付、接客業など（学歴としては「普通高校卒業」扱い） |
| **専業主婦** | 10% | 在学中に相手を見つけ、卒業と同時に結婚・出産 |

> 「先生の場合はね、BabyDoll → DollHouse → DollGarden って、8年間働いて。

> 
> 正直、教壇に立つなんて思ってなかった。
> でも、自分が教わったことを次の世代に伝えるのも、悪くないなって。
> 
> ……それに、生徒のみなさんを見てると、昔の自分を思い出すの。
> 怖かった頃の自分、頑張った自分、初めて気持ちよくなれた自分。

> 
> だから先生、この仕事が好き。
> ふふ、ちょっとカッコつけすぎたかな？」
