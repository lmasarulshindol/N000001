# 初等部 実践教育カリキュラム

> 対象：初等部5〜6年生（10〜12歳）
> 期間：早熟クラス選抜後〜卒業まで（最長2年間）

---

## カリキュラム概要

初等部の実践教育は、段階的に様々な状況・形態を経験し、将来の本格的な実習（中等部以降）に備えるための基礎を築くことを目的とする。

---

## 第1段階：基礎編（5年生・選抜直後〜）

### 1-1. 適性試験
- **形態**: 男1：女1
- **内容**: キス、愛撫、指挿入、男性器への順応、初挿入、中出し
- **目的**: 基本的な受け入れ能力の確認、処女喪失、初体験
- **回数**: 1回（合格後、通常実習へ移行）

### 1-2. 通常実習（基本形）
- **形態**: 男1：女1
- **頻度**: 週2回
- **内容**: 
  - 前戯（キス、愛撫、クンニ）
  - 本番（正常位、騎乗位、後背位）
  - 中出し（ピル服用中のため基本OK）
- **目的**: 基本技術の習得、体の順応、快感への慣れ

---

## 第2段階：応用編（5年生後半〜6年生）

### 2-1. ゴム有り・ゴム無しの感覚比較
- **形態**: 男1：女1
- **内容**:
  - 同一セッション内でコンドーム有り→無しの比較
  - 生挿入時の「熱さ」「密着感」「精液の感覚」を体験
  - 中出し時の「どくどく」という射精感覚の違い
- **目的**: 
  - 生の感覚を知ることで、本番への心構えを作る
  - 「ゴムが破れた」等の緊急時にパニックにならない心理的準備
- **教育ポイント**:
  - 「ゴムありでも気持ちいい」「ゴムなしはもっと気持ちいい」の両方を理解
  - どちらが良い悪いではなく、「違いを知る」ことが目的

### 2-2. 焦らしプレイ
- **形態**: 男1：女1
- **内容**:
  - 寸止めを繰り返し、絶頂を先延ばしにする
  - 「イきたい」と言わせるまで焦らす
  - 最終的に許可を得てからイかせる
- **目的**:
  - 自分の体の反応をコントロールする練習
  - 「欲しい」「イきたい」と言葉にする訓練
  - 感度の向上、より強いオーガズムの経験
- **教育ポイント**:
  - 焦らされることで「自分から求める」姿勢を学ぶ
  - 言葉での意思表示の重要性

## 第3段階：複数形態編（6年生）

### 3-1. 男2：女1（3P・ダブル）
- **形態**: 男性教官2名、生徒1名
- **内容**:
  - 前後同時挿入（口と膣 / 膣と肛門は初等部では非推奨）
  - 交互挿入（一人が挿入中、もう一人は愛撫）
  - 連続射精（一人が中出し後、もう一人も中出し）
- **目的**:
  - 複数の男性を同時に相手する技術
  - 注意の分散と集中の切り替え
  - 連続で精液を受け入れる心理的準備
- **注意点**: 生徒の体力・精神状態を十分に考慮

### 3-2. 男1：女2（レズ込み3P）
- **形態**: 男性教官1名、生徒2名
- **内容**:
  - 女子同士でのキス・愛撫（ウォーミングアップ）
  - 一人が本番中、もう一人は見学 or 愛撫サポート
  - 交代での本番、連続中出し
  - 女子同士での事後処理（舐め合い）
- **目的**:
  - 女性同士の連携プレイの基礎
  - 「見られながら」の羞恥心克服
  - 仲間との協力・競争意識
- **ペア例**: ひなた＆小雪、葵＆みこと など性格の異なる組み合わせ推奨

### 3-3. 女1：男多数（輪姦形式）
- **形態**: 生徒1名、男性教官3〜5名
- **内容**:
  - 複数の男性に囲まれ、順番に相手をする
  - 口・手・膣を同時に使う場面あり
  - 連続での中出し（計3〜5発）
  - 精液まみれになる体験
- **目的**:
  - 多人数相手の心理的耐性
  - 体力・持久力の限界を知る
  - 「使われる」感覚への順応（将来の風俗業務想定）
- **実施条件**: 
  - 基礎編・応用編を十分に修了した生徒のみ
  - 本人の希望と保護者同意が必須
  - 事前の心理カウンセリング実施

### 3-4. 男3：女3（グループセッション）
- **形態**: 男性教官3名、生徒3名
- **配置**: 円形または三角形で、お互いの顔が見える位置
- **内容**:
  - 同時進行での本番（3組が同時に行為）
  - 他のペアの様子を見ながらの行為
  - 途中でパートナーチェンジ
  - 全員が全員と経験する（総当たり）
- **目的**:
  - 「見られる」「見る」の同時体験
  - 仲間の反応から学ぶ（「あの子はあの体位で感じてる」等）
  - 競争意識と連帯感の両立
  - 羞恥心の完全克服
- **教育ポイント**:
  - 終了後に全員でフィードバック会を実施
  - 「〇〇ちゃんの声が可愛かった」等、ポジティブな共有
  - 比較による劣等感が生まれないよう、教諭がフォロー

## 第4段階：特殊編（6年生・希望者のみ）

### 4-1. 擬似強制プレイ（無理やり）
- **形態**: 男1：女1（＋立会教諭必須）
- **内容**:
  - シナリオに基づいた「抵抗→屈服」のロールプレイ
  - 言葉での抵抗（「やめて」「いや」）を演技
  - 体を押さえつけられての挿入
  - 泣きながらのオーガズム演技
- **目的**:
  - 将来的な「プレイ」としての需要への対応
  - 「本当の嫌」と「演技の嫌」の区別をつける訓練
  - セーフワードの使い方を学ぶ
- **絶対ルール**:
  - セーフワード（例：「赤」）で即時中断
  - 事前に台本を共有し、流れを把握
  - 事後の心理ケア必須（「これは演技だった」の確認）
  - 本人の強い希望がある場合のみ実施
- **注意**: トラウマ化を防ぐため、過去に虐待経験のある生徒は対象外

### 4-2. 長時間耐久プレイ
- **形態**: 男1（交代あり）：女1
- **内容**:
  - 2〜3時間の連続セッション
  - 複数回の中出し（5回以上）
  - 途中休憩あり（水分補給・軽食）
  - 体力の限界への挑戦
- **目的**:
  - 持久力の養成
  - 長時間接客への心理的準備
  - 「もう無理」からの「まだできる」の体験
- **対象**: 体力に自信のある生徒（みこと向け）

## 評価基準

| 段階 | 項目 | 評価ポイント |
|------|------|-------------|
| 基礎 | 受け入れ能力 | 痛みへの耐性、順応速度 |
| 基礎 | 声・反応 | 自然な声が出せるか、演技に頼らないか |
| 応用 | 感覚の言語化 | 「気持ちいい」「もっと」等の表現力 |
| 応用 | 自発性 | 自分から求める姿勢 |
| 複数 | 対応力 | 複数相手でもパニックにならないか |
| 複数 | 協調性 | 他の生徒との連携 |
| 特殊 | 演技力 | シナリオ通りに演じられるか |
| 特殊 | 自己管理 | 限界を知り、適切に休憩を取れるか |

## 進級・卒業要件

### 早熟クラス修了要件（5年→6年）
- [ ] 基礎編（1-1, 1-2）完了
- [ ] 週2回の通常実習を3ヶ月以上継続
- [ ] 男性教官からの評価「可」以上

### 初等部卒業要件（6年→中等部）
- [ ] 応用編（2-1, 2-2）完了
- [ ] 複数形態編のうち、最低2種目を経験
- [ ] 累計実習回数 50回以上
- [ ] 卒業実技試験 合格

## 安全管理

- 全セッションに女性教諭（立会い）が同席
- 生徒の体調チェック（事前・事後）
- 心理カウンセラーへの相談窓口を常設
- 「NO」と言える権利の保障（どの段階でも中断可能）
- 月1回の健康診断、性病検査

---

## 備考

- カリキュラムはあくまで目安であり、生徒の発達・希望に応じて調整可能
- 特殊編は義務ではなく、全て選択制
- 中等部進学後は、さらに高度なカリキュラムへ移行
