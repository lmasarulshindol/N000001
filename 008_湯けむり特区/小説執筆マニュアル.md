# 小説執筆マニュアル：湯けむり特区「星降りの宿」

## 作品情報

- 作品名：星降りの宿 — あかりルート「陽だまりの天使」
- 視点：一人称「俺」（30代後半の男性客）
- 対象ヒロイン：日向あかり（18歳）
- 文体：地の文は過去形ベース。字下げは全角スペース
- 本文保存先：`本文/` 配下

## 絶対ルール

1. テキスト結合は Task ツール禁止。Python スクリプトで行う
2. PowerShell では HEREDOC 禁止。UTF-8 設定は毎回必須
3. 並列執筆は最大4エージェント
4. あかりは18歳。年齢を下げない。他キャラの性行為は書かない
5. 各話は本文だけで約10,000字（9000〜11000字）。見出しやメモは字数に含めない

## 描写方針（確定）

- 性行為シーンを各話の主軸にする（分量の半分以上）
- 各話に射精を必ず入れる
- 第1話：手コキ→フェラ→口内射精（挿入なし）
- 第2話以降：挿入あり、中出し必須
- 身体部位・行為は婉曲にしすぎず短い日本語で書く
- あかりの口調：「えへへ〜」「そうなんだ〜」「よしよし〜」、ですます基調
- あかりの一人称：仕事中は「私」、素が出ると「あたし」も可
- イク時は「ふわぁ」と力が抜ける声
- 弱点：耳、首筋、焦らし
- 道徳説教や免罪符の長文化はしない

## 作業フロー

```
設定確認 → 話分割(4以下) → 並列執筆(Task) → 字数確認(Python) → 必要なら結合(Python)
```

## 字数確認用 Python

```python
from pathlib import Path
p = Path(r"本文/第1話_星空の下で.md")
text = p.read_text(encoding="utf-8")
# 見出し行と空行を除いたおおよそ
body = "\n".join(line for line in text.splitlines() if not line.startswith("#"))
print(len(body.replace("\n", "")))
```
