## 世界観：湯けむり特区

### 法的背景（フィクション設定）

20XX年、日本政府は少子高齢化対策と地方創生の一環として、特定地域に「子作り観光特区」制度を試験導入。泡児島に続く第二の特区として、山梨県北部の山間地域に**「湯けむり特区」**が認定された。

この特区内では、通常の法規制から逸脱した特別法が適用され、18歳未満の少女による「おもてなしサービス」が合法的に提供される。

### 特区のルール

| 項目 | 規定 |
|------|------|
| 登録年齢 | 10歳以上 |
| 労働時間 | 1日6時間以内、週30時間以内 |
| 休日 | 週2日以上必須 |
| 健康管理 | 週1回の定期健診義務 |
| 収入 | 政府管理口座で透明化、本人に70%・施設に30% |
| 避妊 | 任意（本人の意思を尊重） |
| 引退 | 25歳で自動卒業、それ以前も自由意思で可能 |
