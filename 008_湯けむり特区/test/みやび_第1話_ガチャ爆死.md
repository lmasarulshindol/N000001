# 第1話 ガチャ爆死

　星降りの宿——山奥にひっそりと佇む、知る人ぞ知る温泉旅館。仕事に疲れ果てた三十代後半のサラリーマンである俺は、有給休暇を使って一人、この宿を訪れていた。

「……あと一人、引けたら編成が完成するんだがな」

　プレイしているのは『ステラクロニクル』——略してステクロ。宇宙を舞台にした美少女×戦略RPGで、最近リリース三周年を迎えた人気タイトルだ。俺はリリース初期からプレイしている古参で、課金額は考えたくないレベルに達している。
