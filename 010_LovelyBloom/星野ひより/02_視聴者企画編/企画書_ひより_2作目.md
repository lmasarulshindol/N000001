# 企画書：星野ひより 2作目（視聴者参加企画）

> 出演: 星野ひより（22歳・Lovely Bloom 在籍）
> ※登場人物は全員成人。すべてのプレイは出演者本人の事前合意に基づく
> 作成: デビュー作撮影の数日後、監督とひよりの打ち合わせで決定

---

## 1. 作品概要

| 項目 | 詳細 |
|------|------|
| メーカー | Petal Pictures（ペタルピクチャーズ） |
| 品番 | PTL-002（予定） |
| ジャンル | 視聴者参加・素人選抜・我慢チャレンジ・手コキ・フェラ・生中出し |
| 撮影 | 撮影用の車（車内パート）＋ 都内ホテル（ご褒美パート）で1日撮影 |
| 出演名 | 星野ひより |

### タイトル（決定）

> **ひよりのご奉仕　10分耐えたら生えっち**
> **〜がまんしてる顔、ぜんぶ見せて〜**

- メイン：監督案。「生えっち」はひよりの普段の言い方をそのまま採用
- サブ：ひより案。「相手の気持ちいい顔を見たい」というデビュー作からの軸を引き継ぐ

### コンセプト

- デビュー作ラストコメント「次は、見てくれてる人と目を合わせながら、してみたい」から発展した企画
- 軸は **「がまんする顔を見つめるひより」**。耐える顔・崩れる顔・中で果てる顔を、ひよりが至近距離で見つめ続ける
- 視聴者から選ばれた参加者が相手なので、画面の向こうの人が「自分もひよりと」と重ねられる作りにする
- ひよりは負けず嫌い。「わざと負けない、手加減なし」と本人が宣言済み

## 2. ルール

| 項目 | 内容 |
|------|------|
| 参加人数 | 応募してきた視聴者から選抜して **4〜5人** |
| 制限時間 | ひとり **10分** |
| 進行 | 手（00:00〜03:00）→ お口（03:00〜07:00）→ 手とお口の両方（07:00〜10:00）。段階的に強くする（ひより案） |
| パイズリ | 最終段階で、ひよりの判断で解禁してよい。射精は胸で受ける（顔射NG） |
| 勝敗 | 10分以内に出したら参加者の脱落。10分耐えきったら参加者の勝ち |
| 勝者のご褒美 | ホテルへ移動して、ひよりと生えっち（中出し） |
| 勝者が複数のとき | ホテルでは **ひとりずつ** 順番に |
| 全員脱落したとき | ひよりへのご褒美として、男優にホテルでたっぷり抱いてもらう（男優は森・黒崎を想定。本人も前向き） |

## 3. パート構成

### Part 1：オープニング

- ひより自身がカメラに向かって企画を説明する（ひより案）
  - 例：「今日はね、応募してくれた視聴者さんに来てもらいました！　ひよりが手とお口で10分間がんばるから、耐えきれたら……生えっち、しよ？」

### Part 2：車内チャレンジ

| 項目 | 内容 |
|------|------|
| 場所 | 撮影用の車の中（外から見えない仕様） |
| 衣装 | 普通の私服 |
| 見どころ | 天井が低く、小柄なひよりが参加者の下にもぐりこんで見上げる形。耐える顔を至近距離で見つめる |

### Part 3：ホテル（ご褒美）

| 項目 | 内容 |
|------|------|
| 場所 | ちゃんとしたホテルの部屋で、ゆっくり |
| 衣装 | コーラルピンクの透け素材ベビードール。**下着なし**で、胸もとも下も全部透けて見える |
| 演出 | 耐えきった人だけが見られる衣装。ドアを開けるとこの姿のひよりが待っている |
| 見どころ | ひとりずつ、10分がまんした人の「いちばん気持ちいい顔」を最後まで見届ける |

### ご褒美パート（ホテル）

主導は10分がまんした男性側。ひよりの体を好きにする。
