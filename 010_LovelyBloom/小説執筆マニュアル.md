## 2. 文体

### 視点と時制

- **三人称一元視点（ひより視点）**。地の文はひよりの内面に寄り添い、ひよりが見たもの・感じたこと・考えたことだけを書く
- 男優や監督の内心は書かない。表情・声・動きからひよりが読み取る形にする
- 時制は過去形を基調にする

### 調子

- ひよりの愛嬌が地の文にもにじむ、明るく甘いトーン。重さや暗さは出さない
- 羞恥はあっても悲壮感にはしない。恥ずかしがりながらも楽しんでいる、が基本線

### 描写の重点（撮影設計書の演出方針と対応）

1. **視線**: 射精の瞬間は、男優の顔とそれを見つめるひよりの気持ちを必ずセットで書く
2. **声の4段階**: インタビューの明るい声 → 恥じらいの小さな声 → 余裕のない高い声 → とろけた素の甘え声。シーンが進むほど段階を上げる
3. **感度の高さ**: 触れられた場所ごとの体の反応（腰が浮く、つま先が丸まる、内側が締まる）で示す
4. **撮影現場の意識**: カメラの赤いランプ、照明の熱、監督の声、レンズが寄ってくる気配。「見られている」感覚で羞恥を強める
5. **衣装の変化**: 私服 → コーラルピンク → 白 → 私服。着替えのたびにひよりの気持ちの変化を一言添える

### 言葉の使い分け

- 地の文は「それ」「熱」「奥」など遠回しの言い方を基本にする
- 直接的な言葉は、ひよりの台詞の中だけで恥じらいとセットで使う。インタビューで言わされた言葉が本番で現実になる「答え合わせ」を効かせるため

### 地の文と台詞の割合

| シーン | 地の文 : 台詞 |
|--------|--------------|
| インタビュー | 3 : 7 |
| 行為シーン | 6 : 4 |
| プロローグ | 7 : 3 |

### 表記

- 読点を減らす。助詞の直後に反射的に打たない。一文に読点が3つ以上続いたら文を分ける
- 名詞を句点でつなぐ羅列は、リズムを出したい箇所に限る
- 台詞の後に「〜と言った」を付けず、前後の地の文で話者を示す
- 三点リーダーは「……」、ダッシュは「――」
- 段落の頭は全角スペースで字下げし、シーン転換は `---` で区切る
- 喘ぎ声は「っ」「……」と地の文の描写で甘さを出す。「♡」「あ゛」、同じ音の連打は使わない

### 人物ごとの口調

| 人物 | 口調・呼び方 |
|------|-------------|
| ひより | 一人称「ひより」。敬語とタメ口が混ざる。口癖は「えっ、うれしい！」「ひより、がんばります！」、照れると「えへへ」。インタビューでは男優を「男優さん」、本番中は「森さん」「黒崎さん」と呼ぶ |
| 監督 | 声だけの登場。柔らかい口調で「〜してみて」「〜なの？」。ひよりを「ひよりちゃん」と呼ぶ |
| 男優A（森 健吾・42） | 穏やかな低い声。「大丈夫？」「ゆっくりね」と気遣う言葉が多い。ひよりを「ひよりちゃん」と呼ぶ |
| 男優B（黒崎 蓮・31） | 口数が少なく、短く少し強気な言葉。「いい声」「まだイけるだろ」。ひよりを「ひより」と呼び捨てにする |

## 4. 執筆フロー

```
設定確認 → 撮影設計書をプロットとして確認 → 4分割 → 並列執筆 → Pythonで結合 → 校正 → Git
```

1. 執筆前に、このマニュアルと参照ファイルをすべて読む
2. 並列執筆は最大4名。各ワーカーへの指示には、担当範囲の設定・セリフ例・このマニュアルの文体ルールを抜粋して入れ、指示だけで書けるようにする
3. 複数ファイルの結合は必ず下の Python スクリプトで行う（エージェントにテキスト結合をさせない）
4. 結合後、推敲チェックリストで全体を校正する
5. Git のコミットメッセージは1行で書く（PowerShell では HEREDOC が使えない）

### 並列執筆の分担

| ワーカー | 担当ファイル | 目標文字数 | 撮影設計書の該当箇所 |
|---------|-------------|-----------|-------------------|
| 1 | `00_プロローグ.md`、`01_オープニングインタビュー.md` | 8,000字 | 4. 当日タイムテーブル、Scene 1 |
| 2 | `02_1回目.md` | 12,000字 | Scene 2 |
| 3 | `03_中間インタビュー.md`、`04_2回目_前半.md` | 10,000字 | Scene 3、Scene 4 の #1〜#4 |

## 5. 結合スクリプト

フォルダ直下に `combine.py` として保存し、`py -3 "c:/Users/MasaruShindo/work2/999_その他/N000001/010_LovelyBloom/combine.py"` で実行する。

```python
"""本文の各パートを結合し、文字数を目標と比べて表示する。"""
import re
from pathlib import Path

BASE = Path(__file__).parent
TITLE = "# 現役ソープ嬢 星野ひより 22歳 AVデビュー（小説版）"
PARTS = [
    ("本文/00_プロローグ.md", 2000),
    ("本文/01_オープニングインタビュー.md", 6000),
    ("本文/02_1回目.md", 12000),
    ("本文/03_中間インタビュー.md", 2500),
    ("本文/04_2回目_前半.md", 7500),
    ("本文/05_2回目_後半.md", 7500),
    ("本文/06_終了後インタビュー.md", 3500),
]
OUTPUT = BASE / "本文/星野ひより_AVデビュー_完全版.md"


def count_chars(text: str) -> int:
    """空白と改行を除いた文字数を返す。"""
    return len(re.sub(r"\s", "", text))


def main() -> None:
    texts = []
    for name, target in PARTS:
        text = (BASE / name).read_text(encoding="utf-8").strip()
        texts.append(text)
        count = count_chars(text)
        print(f"{name}: {count:,}字（目標 {target:,}字、{count / target:.0%}）")
    OUTPUT.write_text(TITLE + "\n\n" + "\n\n---\n\n".join(texts) + "\n", encoding="utf-8")
    total = sum(count_chars(t) for t in texts)
    print(f"結合完了: {OUTPUT.name}（合計 {total:,}字）")


if __name__ == "__main__":
    main()
```
