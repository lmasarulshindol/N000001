## 3. サービスの流れ

### 半個室コース（S-01〜S-02）例

```
入店 → 会員認証（アプリQR）
  → 半個室へ案内（担当子がメニュー説明）
  → 食事注文（任意）
  → 特別メニュー開始（カーテン閉）
  → 時間内サービス
  → 会計（ドリンクバー等は通常精算と合算可）
  → お見送り「またいらしてくださいね」
```

### VIPフルコース（S-05〜S-07）例：90分

```
12:00  受付・指名確認・健康チェック表示確認
12:05  担当子が1Fで出迎え → 2F個室へ
12:10  お茶・おしぼり・今日の流れ説明（合意の再確認）
12:20  スキンシップ開始（制服のまま）
12:40  メイン行為（コース内容に準拠）
13:20  シャワー・着替え補助・アフタートーク
13:30  お見送り（希望者は1Fで軽食可）
```

### 接客トーンの原則
1. **最初から最後までファミレス店員の口調**を崩しすぎない
2. 「ご注文はお決まりですか？」「こちら、生でよろしいですか？」等、**飲食用語で性を言い換える**のが店の遊び
3. 拒否・中断はいつでも可。担当子が「ちょっと休憩にしますね」と言えば客は従う

## 5. 会員制度

### 入会
- 20歳以上・身元確認・性病検査（3ヶ月ごと更新）
- 入会金 ¥30,000／年会費 ¥12,000
- 紹介制推奨（初回来店は体験会員として半個室まで）

### ランク

| ランク | 条件 | 特典 |
|--------|------|------|
| レギュラー | 入会時 | 特別メニュー利用可 |
| シルバー | 月2回以上 | 指名料10%OFF |
| ゴールド | 月4回以上 | 半個室優先、デザートサービス |
| プラチナ | 累計50回 | S-06優先予約、閉店あと解放 |

### 禁止事項
- 同意なき行為・暴力・強要
- 一般フロアでのAIS強要（発覚即退店・除名）
- 無断撮影・配信
- キャストへの店外強要（連絡先交換は店舗管理の範囲のみ）
