# 第1話プロット：ぽぷらの接客風景

| 項目 | 内容 |
|------|------|
| 仮題 | ご注文は、先輩ですか？ |
| 視点 | ぽぷら一人称「私」（素で「あたし」可） |
| 時 | 土曜の昼〜夕方シフト |
| 場所 | 1F軽く → 主に2F VIP「ポプラ」部屋 |
| 分量目安 | 本文 12,000〜16,000字（3接客のため上限緩和） |

## 構成

### 冒頭（〜800字）
開店前〜フロア。牛乳、佐藤に踏み台、身長ネタ、「ちっちゃくないよ！」。AIS予約3件の確認。先輩モードで気合。

### 1人目・三浦健（みうら けん）35歳・初回シルバー手前
- コース: 手コキ → パイズリ射精 → フェラ射精（挿入なし）
- 食事: ハンバーグセットを軽く触れる
- 核: 丁寧な初回接客、胸の大きさへの言及で照れ、名前は間違えないが舌足らず
- 射精2回（パイズリ／口内）

### つなぎ（〜400字）
制服直し、手洗い、牛乳、八千代に「大丈夫？」、次の予約へ。

### 2人目・片梨宗太（かたなし そうた）※ぽぷらが「かたなし」と呼ぶ設定の客 28歳
- 本名: 高梨（たかなし）→ ぽぷらは「かたなしさん」
- コース: 前戯 → 生本番（中出し1）
- 核: 名前呼び間違いギャグ、頭を撫でられて怒る、座位で足が床につかない
- 「生しぼり」「中まで火を通す」

### つなぎ（〜400字）
シャワー短め、足ががくがく、佐藤に「顔赤いぞ」と言われて否定。

### 3人目・遠野誠（とおの まこと）42歳・ゴールド常連
- コース: 前戯 → 生本番×2（中出し2）
- 核: 常連なので呼吸が合う、1回目後「もう一品」、2回目は後背位など体位変化、感度で先輩モード崩壊気味
- 締め: お見送り、エプロン直し、また牛乳、「今日もお疲れさまでしたー！」

## 描写方針
- 食事と性をセット
- 飲食言い換えは適度
- オープンフロア本番なし
- 道徳説教なし
