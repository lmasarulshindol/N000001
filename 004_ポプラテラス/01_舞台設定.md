# 舞台設定：ファミリーレストラン「ポプラテラス」

> ⚠️ 本設定は架空の世界観に基づくフィクションです

---

## 1. 世界観概要

少子化と労働力不足が進んだ近未来の日本。政府は「若年就労特別法」により、10歳以上の性風俗就労を合法化した（001_BabyDoll と同系世界）。

その延長として、飲食業にも **「付帯親密サービス（AIS＝Attached Intimate Service）」** が認可された。登録店舗は通常の食事提供に加え、会員向けの性的サービスを同一施設内で合法提供できる。

ファミレス「ポプラテラス」は、表では普通のファミリーレストラン、裏（会員ゾーン）ではフロアスタッフによる性的サービスをセットで提供する店舗である。

### 時代・場所

| 項目 | 内容 |
|------|------|
| 時代 | 203X年頃（若年就労特別法施行後） |
| 所在地 | 北海道・札幌市郊外のロードサイド（架空） |
| 周辺 | 駐車場広め。チェーン店に見える外観。看板は緑と白 |
| 建前 | 「家族で楽しめるアットホームなファミレス」 |
| 本音 | 会員証を持つ客だけが、特別メニューと個室コースを利用できる |

### 法的枠組み（フィクション）

| 項目 | 規定 |
|------|------|
| 根拠法 | 若年就労特別法＋飲食業AIS認可 |

| 収入配分 | 売上のキャスト取り分55%／店舗45% |

## 2. 店舗コンセプト

**「いらっしゃいませ——ご飯も、からだも、あったかくするね」**

- **表層**: WORKING!! 系の明るいファミレス日常。制服の子が走って注文を取り、皿を運び、笑顔で接客する
- **深層**: 同じ制服・同じ笑顔のまま、個室や半個室で性的サービスに移行する
- **エロスの核**: 「日常接客の延長線上にある性」。非日常のソープではなく、ハンバーグの匂いが残る空間での親密さ

### 差別化（既存作品との位置）

| 作品 | 核 |
|------|-----|
| 001 BabyDoll | 専門ソープ。個室浴場が主戦場 |
| 002 泡児島 | 子作り観光特区・リゾート |
| 003 湯けむり特区 | 温泉旅館の夜通しおもてなし |
| **004 ポプラテラス** | **ファミレス日常＋AIS。食事と性のセット** |

## 3. 施設概要

### 外観
- 2階建て。大きなガラス窓、緑の看板、ポプラのイラストロゴ
- 夜は看板ライトが淡い緑。一見どこにでもあるロードサイド店
- AIS表記は外から見えない（会員アプリ／口コミのみ）

### フロア構成

| エリア | 内容 |
|--------|------|
| **1F 一般フロア** | テーブル席・ファミリー席。食事のみ。一般客OK |
| **1F カウンター** | キッチン前。短時間客・常連の軽食 |
| **1F 半個室ブース** | カーテン仕切り6席。会員のみ。軽度AIS可（机下・座位中心） |
| **2F VIP個室** | 完全個室6部屋。ベッド兼ソファ、シャワー、防音。フルサービス |
| **2F 控え室** | キャスト更衣室・休憩・ロッカー・簡易学習スペース |
| **バックヤード** | 厨房、倉庫、店長室、医務コーナー |

### 内装テイスト
- 木目＋クリームホワイト。観葉植物多め
- 制服の子が映える明るさ。昼はファミリー、夜は少し落とす間接照明
- VIP個室は「ちょっと広めの控室」風。ラブホ感を抑えてファミレス延長の空気を残す

## 4. 運営

### オーナー／店長

**白峰 杏（しらみね あん）** 32歳・女性

- 元大手ファミレスSV。AIS解禁を機に独立開業
- 「飯がまずかったら意味がない」が口癖。性サービスも接客品質で勝負する方針
- 従業員の学業・健康を最優先。無理なシフトは切る
- 表では厳しい店長、裏では子たちの盾

### 採用方針
- 明るさ・素直さ・接客向きの子を優先（「いやし系」歓迎）
- 未経験OK。入店後2週間は食事接客のみ→同意のうえAIS研修
- 住み込み寮あり（徒歩3分のアパート1棟を借り上げ）

## 6. 物語上の役割

この舞台は次を同時に成立させるために設計されている。

1. **日常コメディの空気**（走って運ぶ、呼び間違い、身長ネタ）
2. **同じ子が性的サービスをするギャップ**
3. **食事→個室への自然な導線**（「特別メニューにしますか？」）
4. **看板娘・種島ぽぷら**を中心にした、純粋さ×先輩意識×身体のサービスの摩擦
