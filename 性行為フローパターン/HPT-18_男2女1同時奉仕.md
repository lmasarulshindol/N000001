# HPT-18(男2女1・同時奉仕)

**ST除外。** 男2・女1。二人に攻められてイカされ、その後 **同時奉仕〜二段フィニッシュ**。  
相手: **M1**（後背→のちお掃除対象）／**M2**（口・手 → のち正常位）。

## 進行イメージ

1. 導入〜前戯（二人から触られる）
2. **両手コキ** → **フェラ＋手コキ同時**
3. **フェラ中に後ろから挿入**（M1）→ 抽送 → **女がイカされる**
4. **M1 中出し**（後背）
5. **M2 正常位挿入 ＋ M1 お掃除フェラ** 同時
6. **M2 中出し ＋ M1 口内射精** 同時
7. 事後

## 使用ノード

| 帯 | ノード |
|----|--------|
| IN | IN00–IN03（状況は二人前提） |
| FP | FP01–FP03, FP11(両手コキ), FP12(フェラと手コキ同時), FP06, FP07 |
| MN | MN00, MN11, MN12, MN15, MN16, MN17, MN21, MN22, MN27 |
| AF | AF01–AF03, AF99 |

## 同時行為の対応表

| ノード | 口／手 | 挿入 |
|--------|--------|------|
| FP11 | 両手＝M1＋M2 | — |
| FP12 | フェラ＝片方、手＝もう片方 | — |
| MN11–MN12 | フェラ＝M2 | 後背＝M1 |
| MN16 | （責め継続） | 後背＝M1 |
| MN17 | （フェラ継続可） | **M1 中出し** |
| MN21–MN22 | **お掃除フェラ＝M1** | **正常位＝M2** |
| MN27 | **口内射精＝M1** | **中出し＝M2**（同時） |

## 執筆メモ

- 説明口調を避け、**二人分の刺激が重なる喘ぎ・身体反応**を優先
- 「一人ずつ順番」にならないよう、同時ノードでは **両刺激を1ブロックに混在**
- MN17 / MN27 の中出しは既存どおり **選択後は許可禁止**（行為→反応）。口内は FIN 口と同様
