## 共通前提

- **場所:** ポプラテラス VIP「ポプラ」部屋
- **相手:** 客 → 文中は「お客さん」
- **一人称:** 私
- **基調:** ですます＋先輩接客は前半寄り。感度で声が裏返り、「ちっちゃくない」は短く刺す。`MN05` 以降は言葉が崩れる
- **執筆方針（改訂後）:** コース説明・研修口上を削り、**喘ぎ・吐息・身体反応**優先
- **中出し / 外出し:** ルート別原稿（`※外出し` / `※外出し後`）。外出し後に「抜かないで」を混ぜない
- **口調参照:** [プロフィール.md](./プロフィール.md) および [../../004_ポプラテラス/02_キャラクター設計.md](../../004_ポプラテラス/02_キャラクター設計.md)

## 使い方

1. シナリオ設計で HPT を選ぶ  
2. 対応する `HPT-xx_セリフ.md` をノード順に並べ、プロット・台本に貼る  
3. AIS用語（生しぼり・盛り付け・ごちそうさま 等）はポプラテラス設定に準拠
