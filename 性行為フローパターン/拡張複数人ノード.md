# 拡張複数人ノード

標準1対1に加える **同時行為・複数相手** ノード。採番はマスタ [性行為フローチャート.md](../性行為フローチャート.md) に準拠。  
相手ラベル: **M1**（先に挿入する側）／**M2**（口・手を主に使う側）／**M3 以降**（3人以上のとき）。  
複数人ノードは **ヒロイン本人が望み、事前に合意した場面** でのみ使う（[HPT-03](./HPT-03_輪姦プレイ.md) §同意）。

## 男2（HPT-02 で使用）

| ノード | 内容 |
|--------|------|
| `FP11(両手コキ)` | 左右で M1・M2 を同時に手コキ（予備） |
| `FP12(フェラと手コキ同時)` | 口で一方、手でもう一方 |
| `MN11(フェラ中・後背位挿入)` | 口＝M2、後背挿入＝M1 |
| `MN12(抽送・口奉仕継続)` | 後背抽送しながらフェラ継続（予備） |
| `MN15(二人責め・接近)` | クライマックス接近（予備） |
| `MN16(二人にイカされる)` | 複数人責めでの女側絶頂 |
| `MN17(1人目中出し)` | M1 中出し（後背） |
| `MN21(正常位＋お掃除フェラ)` | M2 正常位挿入と同時に M1 のお掃除フェラ |
| `MN22(抽送・お掃除継続)` | （予備） |
| `MN27(中出しと口内射精同時)` | M2 中出し ＋ M1 口内射精を同時 |

## 3人以上（HPT-03 で使用）

| ノード | 内容 |
|--------|------|
| `MN31(交代・2人目挿入)` | 1人目の直後に M2 が交代で挿入 |
| `MN32(三人同時・騎乗＋口＋手)` | M3 に騎乗、M1 を口、M2 を手 |
| `MN33(連続中出し)` | M2・M3 が続けて中出し |
| `MN34(最後の一人・ぶっかけ)` | 最後は顔・胸へ射精 |
| `MN35(二人同時ぶっかけ)` | 男2女1の締め。二人が同時に顔と胸へ射精 |
| `MN36(口内射精・ごっくん)` | 騎乗中に口の相手が口内射精、ヒロインが飲み込む |

## フラグ

| フラグ | 設定 | 影響 |
|--------|------|------|
| `protection` | MN00（自動挿入・生固定） | 挿入時の反応 |
| `finish` | フロー定義の `finish: "中"` | AF01 を中出し後として解決 |
