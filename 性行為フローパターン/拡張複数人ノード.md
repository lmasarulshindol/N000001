# 拡張複数人ノード（男2女1）

標準1対1に加える **同時行為・複数相手** ノード。採番はマスタ [性行為フローチャート.md](../性行為フローチャート.md) に準拠。  
相手ラベル: **M1**（先に挿入する側）／**M2**（口・手を主に使う側 → のち交代可）。

| ノード | 名称 | 内容 |
|--------|------|------|
| `FP11(両手コキ)` | 両手コキ | 左右で M1・M2 を同時に手コキ |
| `FP12(フェラと手コキ同時)` | フェラ＋手コキ | 口で一方、手でもう一方 |
| `MN11(フェラ中・後背位挿入)` | フェラ中に後ろから挿入 | 口＝M2、後背挿入＝M1 |
| `MN12(抽送・口奉仕継続)` | 抽送（フェラ継続） | 後背抽送しながらフェラ継続 |
| `MN15(二人責め・接近)` | クライマックス接近 | 二人に攻められて感度上昇 |
| `MN16(二人にイカされる)` | 女側絶頂 | 二人責めでの絶頂 |
| `MN17(1人目中出し)` | M1 中出し（後背） | 後背のまま M1 射精（生固定） |
| `MN21(正常位＋お掃除フェラ)` | 正常位挿入＋お掃除 | M2 正常位挿入と同時に、M1 のお掃除フェラ |
| `MN22(抽送・お掃除継続)` | 抽送（お掃除継続） | |
| `MN27(中出しと口内射精同時)` | 同時フィニッシュ | M2 中出し ＋ M1 口内射精を同時 |

## フラグ

| フラグ | 設定 | 影響 |
|--------|------|------|
| `protection` | MN00 相当（各挿入前） | `MN17` / `MN27` の中出し表現（生／ゴム） |
| `finish` | 各 MN17/MN27 | 中／外。口側は口内固定が多い |
