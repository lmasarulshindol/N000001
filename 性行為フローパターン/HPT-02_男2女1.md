# HPT-02(男2女1)

**本番あり・男2人（M1・M2）。** 二人がかりの愛撫で1回イかせ、両手コキ・フェラ・パイズリで二本に奉仕。本番は後背位＋フェラ → 中出し → 交代して正常位＋お掃除フェラ → 中出しと口内射精同時 → 最後に二人同時ぶっかけ。

## 使用ノード

| IN | FP | MN | AF |
|----|----|----|----|
| 00, 02, 03 | 01, 04, 11, 12, 17 | 00(自動), 11, 12, 16, 17, 21, 22, 27, 35 | 01, 02, 99 |

```mermaid
flowchart TD
    IN00([IN00(Hシーン開始)]) --> IN02[IN02(キス・抱き寄せ)] --> IN03[IN03(衣服を乱す/脱衣開始)]
    IN03 --> FP01[FP01(胸・首筋への愛撫)] --> FP04[FP04(手指での愛撫)] --> FP11[FP11(両手コキ)]
    FP11 --> FP12[FP12(フェラと手コキ同時)] --> FP17[FP17(パイズリ奉仕)] --> MN00[MN00(生で挿入)]
    MN00 --> MN11[MN11(フェラ中・後背位挿入)] --> MN12[MN12(抽送・口奉仕継続)] --> MN16[MN16(二人にイカされる)]
    MN16 --> MN17[MN17(1人目中出し)] --> MN21[MN21(正常位＋お掃除フェラ)] --> MN22[MN22(抽送・お掃除継続)]
    MN22 --> MN27[MN27(中出しと口内射精同時)] --> MN35[MN35(二人同時ぶっかけ)]
    MN35 --> AF01[AF01(余韻・呼吸を整える)] --> AF02[AF02(抱き合い・会話)] --> AF99([AF99])
```

## 同時行為の対応

| ノード | 口／手／胸 | 挿入 |
|--------|------------|------|
| FP01 | 二人で左右の胸・首筋 | — |
| FP04 | M1＝指、M2＝乳首・クリ | — |
| FP11 | 両手で M1・M2 | — |
| FP12 | 口と手を M1・M2 で交互 | — |
| FP17 | 胸＝M1、手＝M2 | — |
| MN11・MN12 | フェラ＝M2 | 後背＝M1 |
| MN17 | — | M1 中出し |
| MN21・MN22 | お掃除フェラ＝M1 | 正常位＝M2 |
| MN27 | 口内射精＝M1 | 中出し＝M2 |
| MN35 | 顔＝M1、胸＝M2 | — |

分岐なし（中出し固定）。`AF01`・`AF02` は中出し後の余韻で書く。
