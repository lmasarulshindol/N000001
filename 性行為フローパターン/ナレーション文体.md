# 性行為フロー ナレーション文体（確定）

> 調査根拠: 官能小説の三人称一元視点・五感描写（『勝ち抜くための描写テクニック』系）、エロゲ地の文の「動作の解像度」（同人エロゲ論）、永田守弘『官能小説の奥義』の直接表現方針。  
> 本プロジェクトの HTML／セリフMD はこの文書に従う。

## 採用する文体

| 項目 | 決定 |
|------|------|
| 視点 | **三人称・ヒロイン一元**（カメラはヒロインの背後。相手の内面は書かない） |
| 時制 | **過去形ベース**（「した」「入ってきた」） |
| 主語 | 適宜省略して没入感を出す（「愛衣は」を毎文繰り返さない） |
| 長さ | ノードあたり **地の文2〜5文** ＋ セリフ。説明講義は禁止 |
| トーン | **生々しく直接的**。婉曲の花・海産物比喩は使わない |

## 書くこと（必須）

1. **行為の物理**: どこに何が触れているか／入っているか（膣・亀頭・クリ・舌・指・精液など直接語で可）
2. **五感**: 熱・ぬめり・水音・肉の打ち合う音・匂い・味・視界のぼやけ
3. **身体反応**: 腰が浮く、内壁が締まる、涎、痙攣、息が詰まる
4. **状態の変化**: 濡れ方、挿入の深さ、テンポ、射精の前後で何が変わったか

## 書かないこと

- 「興奮した」「気持ちよかった」だけの抽象語で終わること
- 講義・設定説明・自己分析の長文
- 相手の心中モノローグ
- 括弧書きのト書きだけ（`（腰が動く）` 単体）— **地の文に昇格させる**

## フォーマット（各ノード）

```markdown
### NODEID(名称)

地の文。二人称呼びは使わず、行為と感覚を直接描く。

「セリフ……っ」

必要なら短い地の文。

「続きのセリフ……っ」
```

- セリフは従来どおりキャラ口調を維持
- `※外出し:` 等の分岐注記は残す（注記側にも短い地の文を足してよい）
- MN00/MN07 の prompt／反応の役割は崩さない（選択前＝許可可、選択後＝反応のみ）

## 年齢帯（18歳〜30代前半・成人のみ）

対象範囲と帯ごとの執筆ルールは [作成ガイドライン.md](./作成ガイドライン.md) §対象年齢。  
地の文では **そのシナリオ期の身体スケール（身長・手の大きさ・着衣）** を一貫させ、別年齢のキャラ原稿から描写だけ借りない。

## キャラ差分（地の文の色）

| キャラ | 地の文の癖 |
|--------|-----------|
| 水原愛衣 | 清楚な外見と貪欲な腰のギャップ。丁寧語が消える過程を動作で（**18〜19歳**帯の代表例） |
| 桜井美月 | 攻めの余裕が崩れる瞬間を身体で見せる。揺れる胸・爪を立てる指・涙目 |
| 早瀬凛 | 無表情の崩れを眉・唇・耳の赤み・指先で追う。セリフより地の文が主 |
| 小野寺ひなた | 柔らかい身体で包み込む描写。抱擁・脚を絡める・とろけた表情 |
