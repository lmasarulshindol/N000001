# HPT-13(対面座位フィニッシュ)

`FP07(挿入準備・体位を整える)` で **対面座位**（向かい合い・抱き合い）。`MN04` は省略し、クライマックスまで同体位。

## 使用ノード

| IN | FP | MN | AF |
|----|----|----|-----|
| 00–03 | 01–07（FP07=対面座位） | 01–03,05–07 | 01–03,99 |

```mermaid
flowchart TD
    IN00([IN00(Hシーン開始)]) --> IN01 --> IN02 --> IN03
    IN03 --> FP01 --> FP02 --> FP03 --> FP04 --> FP05 --> FP06
    FP06 --> FP07[FP07(挿入準備)・対面座位]
    FP07 --> MN00[MN00(生で挿入)]
    MN00 --> MN01[MN01(挿入)・対面座位]
    MN01 --> MN02 --> MN03 --> MN05 --> MN06 --> MN07
    MN07 --> AF01 --> AF02 --> AF03 --> AF99([AF99])
```

## 設計メモ

- 顔を見せ合う・感情が漏れやすい。「ただいま。」1回目核心向け。
- HPT-07(騎乗) と対になる **ヒロイン正面・密着** 型。
