## 共通前提

- **対象年齢:** 18歳（成人・製菓専門学校1年生）。年齢帯「10代後半」。学生服・制服の描写は使わない
- **見た目・物腰:** おっとり癒し系・甘えん坊・肉感的
- **核:** 快感に素直で、とろけていく
- **シナリオ:** 恋人・悠真（24歳会社員）のマンションにお泊まり（HPT-01）
- **相手呼び:** 悠真さん（`MN03` 以降は「ゆうまさぁん」）
- **一人称:** わたし
- **FP08(パイズリ):** 可
- **口調参照:** [プロフィール.md](./プロフィール.md)

## 執筆方針

- 羞恥より素直さ。「きもちいい」「すき」を早めに出してよい
- 柔らかい身体で包み込む描写（抱擁・脚を絡める・胸の重み）を地の文で
- 幼児語は使わない（甘えは大人の甘え方で）
- 中出し／外出しはルート別（外出し後に「抜かないで」を混ぜない）
