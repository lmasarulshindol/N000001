# 性行為フローパターン — 作成ガイドライン

本フォルダで **HPT（進行の型）** と **キャラ別セリフ** を追加・改稿するときの手順と規約。  
AI（Cursor）による執筆・改稿もこの文書に従う。

## 対象年齢（ヒロイン）

**10歳（佐藤莉子・作品期想定の下限例）〜 30代前半女性** を想定する。  
HPT ノード列そのものは年齢非依存。**年齢差は `{キャラ}/README.md` の「対象年齢・期」と、地の文・セリフ・ノードNGで吸収**する。

| 帯 | 目安 | 地の文 | セリフ・口調 | ノード上の注意 |
|----|------|--------|--------------|----------------|
| **幼少〜低学年** | 10歳前後（莉子・特定シナリオ期） | 細い肢体・未発達な輪郭を物理描写で。身長差・服サイズを明示しやすい | 一人称・相手呼びは作品設定準拠。小悪魔等の「演技」は短く | **FP08(パイズリ) 不可**（HPT-16/17 は口・手・素股）。作品側の禁止ノードがあれば README に列挙 |
| **10代後半** | 17〜19（例: 水原愛衣 19） | 清楚／制服／初々しさと反応のギャップ | 丁寧語→崩れ。自己説明より喘ぎ・身体 | 標準 HPT。胸・谷間描写はキャラプロポーションに合わせる |
| **20代** | 大学生〜社会人 | 腰・持久・主導／受けのバランス | 口調はキャラ設計どおり | 多回戦・体位多段（HPT-09/11/12）を使いやすい |
| **30代前半** | 28〜34 | 落ち着いた色気・筋肉／脂肪の付き方・疲れ／余裕 | 敬語残り・経験を匂わせる語彙可（説教口調は禁止） | 事後厚め（HPT-10）・AF10 インタビュー向き。無理な幼語は使わない |

**運用ルール**

1. セリフ MD ヘッダまたはキャラ README に **`対象年齢:`（または「○歳期・BD-HJ01 想定」）** を必ず1行書く。未記載のまま別年齢の地の文を流用しない。
2. 同一キャラでも **期・シナリオで年齢が変わる** 場合は、フォルダを分けるか、ファイル名・ヘッダで期を区別する（例: 10歳期用 HPT と VIP 接客期用 HPT を混在させない）。
3. 年齢帯をまたいだ **別キャラ原稿のコピペ禁止**（口調だけでなく、身体スケール・ノード可否を必ず差し替える）。
4. VN テスト用の3キャラ（莉子／ぽぷら／愛衣）は **各 README の年齢・期** を正とする。新規キャラは帯の代表例にならなくてよいが、帯のどこに載せるか README に明記する。

## 2. 新規 HPT を足すとき

1. **マスタ確認** — [性行為フローチャート.md](../性行為フローチャート.md) に無いノードIDを勝手に作らない。拡張は既存の `FP08–12` / `MN11–27` / `IN10` / `AF10–11` 等の帯に合わせる。
2. **HPT-xx ファイル作成**
   - タイトル: `# HPT-xx(表示名)`
   - **使用ノード**表（IN / FP / MN / AF）
   - **省略・追加**を1行メモ（README の比較表に追記する）
   - **Mermaid** `flowchart TD`（ラベルは `ID(名称)`）
   - 特殊事項: `ST` 含有（HPT-15 のみ標準）、挿入なし（HPT-17）、複数人（HPT-18）等

   - HPT-17 は `branch`（FP03 後の奉仕選択）、HPT-15 は `ST01–03` + 必要なら HPT-04 相当の FP 順
5. **3キャラ分**の `HPT-xx_セリフ.md` を用意（後述）。未執筆でも VN 用に HPT-01 ベースマージは動くが、本番用は必ず執筆する

## 3. キャラ別セリフ MD の書き方

### 3.1 ファイルヘッダ

```markdown
# HPT-xx(表示名) — {キャラ名}セリフ

> 対象年齢: …歳（または ○期・{シナリオID} 想定）／相手: …／場所: …  
> 執筆方針: [ナレーション文体.md](../ナレーション文体.md) 準拠。{キャラREADMEの要点}

---
```

キャラ固有の前提は **{キャラ}/README.md** を正とし、ヘッダで矛盾させない。

### 3.2 ノード見出し（必須形式）

```markdown
### MN03(テンポを上げる)

地の文2〜5文。

「セリフ……っ」

---
```

- 見出しは **`###`** + **`NODEID(名称)`**（名称はマスタと一致させる）
- ノードブロックの区切りは **`---`** 単独行（`build_vn_data.py` が分割に使用）
- 複数ラウンド（HPT-09/11）: `### 【2回目】MN01(挿入)` のように **IDは文中に含める**（パーサは `MN01` を抽出し、同一IDは **リストとして連結**）

### 3.3 地の文とセリフ

[ナレーション文体.md](./ナレーション文体.md) に従う。

- 地の文: 三人称・ヒロイン視点・過去形・物理と五感
- セリフ: キャラ口調（一人称・相手呼びは README 準拠）
- **禁止**: 講義・設定説明・相手の内心・抽象語だけのノード

### 3.4 流用・短縮

| 方法 | 書き方 | 挙動 |
|------|--------|------|
| 別ファイル参照 | 本文に「HPT-01 同様」「HPT-04 使用」等 | 同一キャラの `HPT-xx_セリフ.md` をマージ |
| 範囲見出し | `### IN00〜FP03` + インライン `**IN00:**` | 手動または部分流用（HPT-17 等） |
| 複合1ブロック | `### MN01〜MN07` + `**MN01:**` … | インライン分割 |

流用してよいのは **同キャラ・同口調** のみ。別キャラからのコピーは口調調整必須。

### 3.5 VN 分岐用の注記行

パーサが認識する形式（**コロンは全角・半角どちらも可**）:

| 記法 | 用途 |
|------|------|
| `※外出し: …` | `MN07` ブロック内 — 外出しルート用（地の文＋セリフ） |
| `※外出し後: …` | `AF01` / `AF02` / `AF03` / `AF10` — 外出し後の差し替え |
| `※中出し後: …` | 同上（中出し専用差し替え） |
| `※生: …` | `MN00` / `MN01` — 生挿入の反応（**ゴム選択肢は廃止・生固定**） |

**ルート混在禁止（最重要）**

- 外出し後の `AF` に「抜かないで」「中、いっぱい」等 **中出し前提** のセリフを入れない
- 中出し側 `MN07` の prompt（選択前）と reaction（選択後）の役割を守る（次節）

### 3.6 MN00 / MN07 / FIN の役割

| キー（生成後） | タイミング | 内容 |
|----------------|-----------|------|
| `MN00` / `MN00:prompt` | 挿入前 | 許可・ねだり（選択前） |
| `MN00:生` | 挿入直後 | **反応のみ**（許可の繰り返し禁止） |
| `MN07` 本文 | フィニッシュ前 | 地の文 + **中出しを促す prompt 相当**（最後の段落はビルド時に reaction へ分割されうる） |
| `MN07:外` | 外出し選択後 | `※外出し:` から生成 |
| `MN07:中:生` / `MN07:外:生` | 選択後 | リアクション専用（許可語は除去される） |
| `AF01:中` / `AF01:外` 等 | MN07 以降 | ルート別事後 |

**HPT-17（奉仕フィニッシュ）**

- `MN01–MN07` は書かない
- `FP03` 後のルート: FP08 / FP05 / FP09 / FP10（キャラにより FP08 不可の注記可）
- `FIN` ノード — VN 上で口／顔／胸／我慢の選択。口調は `{キャラ}` の DEFAULT_FIN 系に合わせる

**保護（生）**

- プロジェクト方針: **`protection=raw` 固定**。セリフにゴム分岐を新設しない

## 4. キャラ追加時

1. フォルダ `{キャラ名}/` を作成
2. `README.md` — HPT-01〜18 へのリンク表、**対象年齢（帯）**、場所・相手呼び・一人称・口調・NG（例: 10歳期は FP08 不可）
3. 必要なら `プロフィール.md`
4. **HPT-01 から順に** `HPT-xx_セリフ.md` を執筆（HPT-01 が **VN マージのベース**）
5. `build_vn_data.py` の `chars` に `char_key`（英小文字）・フォルダ名・表示名を追加
6. `DEFAULT_MN00` / `DEFAULT_MN07_*` / `DEFAULT_AF_AFTER` / `DEFAULT_FIN_PROMPT` にフォールバック用1行を追加（分岐自動分割の保険）

`char_key` 例: `riko` / `popura` / `ai`

## 5. 執筆ワークフロー（人間・AI 共通）

```
HPT選定 → HPT-xx定義確認 → キャラREADME確認 → ナレーション文体確認
    → HPT-xx_セリフ.md 執筆（ノード順）
    → py -3 build_vn_data.py
    → flow-vn-test.html で完走・分岐確認
    → （任意）作品個別フローチャートと突合
```

### AI（Cursor）向けルール

- 作業開始前に **上表「関連ドキュメント」** と **対象キャラ README** を Read で読む
- 複数 HPT / 複数キャラの新規執筆は **最大4並列**（Task）まで。各指示は **ノード一覧・口調・禁止事項を自己完結** で含める
- **複数 MD の結合は Python スクリプト**（Task で長文結合しない）
- PowerShell: `py -3` 使用、`&&` 不可、コミットメッセージは1行（[powershell-pitfalls](../../.cursor/rules/powershell-pitfalls.mdc)）

### パターン別の注意

| HPT | セリフ執筆の要点 |
|-----|------------------|
| 01 | 全ノードの基準原稿。体位変更なし |
| 02 | FP01–05 省略 — 短い橋渡しを IN 側で |
| 04 | FP05→FP04 の順。口内射精想定なら MN07 前後を口寄りに |
| 05 | FP05 省略、FP04→FP06。挿入前絶頂 |
| 06/08/12/13 | `MN04` の体位を定義どおり固定 |
| 07 | 騎乗・主導感（MN04 省略） |
| 09 | 【1回目】【2回目】見出し。1回目後 **AF01 短尺のみ** |
| 10 | `AF10` を厚く |
| 11 | ラウンド間 `AF01` 短尺 + `AF10`。2回目以降 FP 省略 |
| 14 | `IN10` から開始 |
| 15 | `ST01–03` + 体部は HPT-04 相当。`AF11` 任意 |
| 16 | `FP08` 必須 |
| 17 | 挿入なし。FP 分岐 + FIN |
| 18 | `FP11–12`, `MN11–27`。相手2名の地の文の切り分け |

## 8. よくあるミス

| 症状 | 原因 | 対処 |
|------|------|------|
| VN でノードが空 | 見出し形式違い、`---` 不足 | `### NODEID(名称)` と `---` を統一 |
| 外出しなのに「中、いっぱい」 | AF ルート混在 | `※外出し後` 側だけ直す |
| 2回目 MN が1回目と同じ | 【2回目】見出しに MNxx が無い | タイトルに `MN01` 等を含める |
| HPT-17 で本番が出る | MN ノードを書いた | MN ブロック削除、FIN/FP のみ |
| ビルド後も反映されない | `vn-data.js` 未再生成 | `build_vn_data.py` 再実行 |
