# HPT-12(体位多段)

1ラウンド内で **MN04(体位変更) を2回以上**。例: 正常位 → 騎乗 → 後背 →（任意）正常位で締め。

## 使用ノード

| IN | FP | MN | AF |
|----|----|----|-----|
| 00–03 | 01–07 | 01–03 → MN04 → 03–07 → MN04 → 05–07 | 01–03,99 |

**拡張ノード（任意）:** `MN04-R2`, `MN04-R3` … 同一 MN04 ID のインスタンス suffix で管理。

```mermaid
flowchart TD
    IN00([IN00(Hシーン開始)]) --> IN01 --> IN02 --> IN03
    IN03 --> FP01 --> FP02 --> FP03 --> FP04 --> FP05 --> FP06 --> FP07

    FP07 --> MN00[MN00(生で挿入)]
    MN00 --> MN01[MN01(挿入)]
    MN01 --> MN02 --> MN03
    MN03 --> MN4A[MN04 1回目・例:騎乗]
    MN4A --> MN3B[MN03(テンポを上げる)]
    MN3B --> MN4B[MN04 2回目・例:後背]
    MN4B --> MN05 --> MN06 --> MN07

    MN07 --> AF01 --> AF02 --> AF03 --> AF99([AF99])
```

## 設計メモ

- 「おかえり。」系の **円環（最初と同じ体位で終わる）** は最後に MN04 を追加して正常位へ戻す。
