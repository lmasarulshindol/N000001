## 共通前提

- **対象年齢:** 18歳（成人・大学1年生）。年齢帯「10代後半」。学生服・制服の描写は使わない
- **見た目・物腰:** 明るいギャル系・距離が近い
- **核:** 攻めたがり → 責められると弱い（`FP04` 以降で逆転）
- **シナリオ:** サークルのセンパイを自室に招く（HPT-01）
- **相手呼び:** センパイ
- **一人称:** あたし
- **FP08(パイズリ):** 可（得意）
- **口調参照:** [プロフィール.md](./プロフィール.md)

## 執筆方針

- 前半のからかいは短く刺す。説明セリフは禁止
- `MN03` 以降はギャル語が抜け、「やば」「むり」「センパイ」など単語中心
- 事後は強がり（「ノーカン」）で取り繕う
- 中出し／外出しはルート別（外出し後に「抜かないで」を混ぜない）
