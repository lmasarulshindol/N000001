# HPT-15(ドキュメンター)

**ST を含む**唯一の公式 HPT。撮影・記録映像向け。  
前半 **ST01–ST03** → 体部は **HPT-04(口先行)** または **HPT-01** を指定して組み合わせる。

## 使用ノード

| フェーズ | ノード |
|---------|--------|
| ストーリー | ST01(イベント・会話進行) → ST02(雰囲気・関係性) → ST03(H突入) |
| 体部（例: 口先行） | IN00–IN03 → FP01–02 → FP05 → FP04 → FP06–07 → MN01–07 → AF01–03,99 |

**採用例:** `HPT-15 + 体部HPT-04`（BD-HJ01）

```mermaid
flowchart TD
    ST01[ST01(イベント・会話進行)] --> ST02[ST02(雰囲気・関係性の変化)]
    ST02 --> ST03[ST03(Hシーン突入トリガー)]
    ST03 --> IN00([IN00(Hシーン開始)])

    IN00 --> IN01 --> IN02 --> IN03
    IN03 --> FP01 --> FP02 --> FP05 --> FP04 --> FP06 --> FP07
    FP07 --> MN00[MN00(生で挿入)]
    MN00 --> MN01[MN01(挿入)] --> MN02 --> MN03 --> MN05 --> MN06 --> MN07
    MN07 --> AF01 --> AF02 --> AF03 --> AF99([AF99])

    AF99 --> AF11[AF11(控え室・ソロ)・任意]
```

## 拡張ノード

| ノード | 用途 |
|--------|------|
| AF11(控え室・ソロ) | カメラ外で仮面が落ちる（BD-HJ01 の AF99 拡張） |

## 設計メモ

- 「はじめて。」シリーズの標準骨格。
- 体部フローは別 HPT を明記すること（本ファイル単体では FP/MN 順を固定しない運用も可）。
