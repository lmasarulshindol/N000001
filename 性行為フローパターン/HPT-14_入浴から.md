# HPT-14(入浴から)

**IN10(入浴・シャワー)** から開始し、ベッドへ移ってから通常前戯〜本番。ST 除外のまま。

## 使用ノード

| 導入 | 以降 |
|------|------|
| IN00 → **IN10(入浴・シャワー)** → IN01(ベッド) | FP01–07 → MN01–07（MN04任意）→ AF01–99 |

**IN01:** 場所の提示を **ベッド側** に再設定（シャワー後の移動後）。

```mermaid
flowchart TD
    IN00([IN00(Hシーン開始)]) --> IN10[IN10(入浴・シャワー)]
    IN10 --> IN01[IN01(場所・状況)・ベッドへ]
    IN01 --> IN02[IN02(キス・抱き寄せ)]
    IN02 --> IN03[IN03(衣服を乱す/脱衣開始)]
    IN03 --> FP01 --> FP02 --> FP03 --> FP04 --> FP05 --> FP06 --> FP07
    FP07 --> MN00[MN00(生で挿入)]
    MN00 --> MN01[MN01(挿入)] --> MN02 --> MN03
    MN03 --> MN4{MN04任意}
    MN4 --> MN05
    MN4 -.->|スキップ| MN05[MN05(クライマックス接近)]
    MN05 --> MN06 --> MN07
    MN07 --> AF01 --> AF02 --> AF03 --> AF99([AF99])
```

## 設計メモ

- BabyDoll「入浴で距離を縮める」導入用。IN10 はマスタ拡張ノード。
