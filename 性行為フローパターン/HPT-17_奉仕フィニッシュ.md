# HPT-17(奉仕フィニッシュ)

**挿入なし**。`FP08(パイズリ)` / `FP05(口)` / `FP09(手コキ)` / `FP10(素股)` のいずれか（または組合）で男性フィニッシュ → 事後。

## 使用ノード

| 使用 | 省略 |
|------|------|
| IN00–IN03, 選択した FP, AF01–AF03, AF99 | MN01–MN07 すべて |

**例A（パイズリ胸射）:** IN → FP01–03 → FP08 → AF  
**例B（口＋手）:** IN → FP05 → FP09 → AF  
**例C（素股）:** IN → FP02 → FP10 → AF  

```mermaid
flowchart TD
    IN00([IN00(Hシーン開始)]) --> IN01 --> IN02 --> IN03
    IN03 --> FP01 --> FP02 --> FP03
    FP03 --> SVC{奉仕}
    SVC --> FP08[FP08(パイズリ)]
    SVC --> FP05[FP05(口での愛撫)]
    SVC --> FP09[FP09(手コキ)]
    SVC --> FP10[FP10(素股)]
    FP08 --> FIN[外出し・胸射等]
    FP05 --> FIN
    FP09 --> FIN
    FP10 --> FIN
    FIN --> AF01[AF01(余韻)]
    AF01 --> AF02 --> AF03 --> AF99([AF99])
```

## 拡張ノード（マスタ）

| ノード | 名称 |
|--------|------|
| FP08(パイズリ) | 胸で挟んで刺激 |
| FP09(手コキ) | 手での刺激 |
| FP10(素股) | 挿入なしで股間摩擦 |
