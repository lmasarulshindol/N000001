# HPT-11(多回戦)

**3〜4回**の本番。各回 `MN07` のあと **AF01(短尺) + AF10(中間インタビュー)** → 次ラウンド。前戯は **1回目のみ**（2回目以降は `MN01` から）。

## 使用ノード

| フェーズ | 流れ |
|---------|------|
| 初回のみ | IN00–IN03, FP01–FP07 |
| 各ラウンド | MN01–MN07（`-R2` / `-R3` / `-R4` suffix） |
| ラウンド間 | AF01(短尺) → AF10(中間) |
| 終了 | AF01–AF03, AF99 |

**省略:** 4回目はシナリオ判断（3回で終了可）。

```mermaid
flowchart TD
    IN00([IN00(Hシーン開始)]) --> IN01 --> IN02 --> IN03
    IN03 --> FP01 --> FP02 --> FP03 --> FP04 --> FP05 --> FP06 --> FP07

    FP07 --> MN00[MN00(生で挿入)]
    MN00 --> R1[MN01–MN07 1回目]
    R1 --> G1[AF01短尺 → AF10中間]
    G1 --> R2[MN01–MN07 2回目]
    R2 --> G2[AF01短尺 → AF10中間]
    G2 --> R3[MN01–MN07 3回目]
    R3 --> G3{4回目?}
    G3 -->|する| R4[MN01–MN07 4回目]
    G3 -->|省略| AFend
    R4 --> AFend[AF01–AF03 → AF99]

    AFend --> AF99([AF99(Hシーン終了→ストーリー再開)])
```

## 設計メモ

- DollHouse 以降の「余裕・複数回中出し」向け。
- HPT-09(二回戦) の拡張。中間 AF10 で小悪魔の取り繕い・販促トークを挟める。
