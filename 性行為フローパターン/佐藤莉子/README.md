## 共通前提

- **対象年齢:** **10歳（作品期・下限想定）** — 本フォルダのセリフはこの期を基準に書く。別期（成長後）を書く場合はヘッダに期名を明記し、10歳期原稿と混在させない
- **場所:** BabyDoll VIPルーム（接客 or 撮影想定どちらでも流用可）
- **相手:** 客／男優 → 文中は「おじさん」
- **一人称:** あたし
- **基調:** 小悪魔・プロ。`MN05` 以降で仮面が剥がれ、絶頂後に取り繕う
- **執筆方針（改訂後）:** 説明・講義口調を削り、**喘ぎ・吐息・身体反応**優先。小悪魔は短く刺す
- **中出し / 外出し:** `MN07:prompt` / `MN07:中` / `MN07:外` と `AF01:中` / `AF01:外`（`※外出し後:`）で別原稿。外出し後に「抜かないで」を混ぜない
- **FP08(パイズリ):** 10歳期は不可 → [HPT-16/17](./HPT-16_セリフ.md) は口・手・素股で代替

## 使い方

1. シナリオ設計で HPT を選ぶ  
2. 対応する `HPT-xx_セリフ.md` をノード順に並べ、プロット・台本に貼る  
3. BD-HJ01 など個別作品は [../../001_BabyDoll/フローチャート_BD-HJ01_莉子_はじめて。.md](../../001_BabyDoll/フローチャート_BD-HJ01_莉子_はじめて。.md) と突合
