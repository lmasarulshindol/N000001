## 共通前提

- **対象年齢:** 18歳（成人・社会人1年目／カフェ勤務）。年齢帯「10代後半」。学生服・制服の描写は使わない
- **見た目・物腰:** 長身・クール・無口
- **核:** 無表情が崩れていく（`MN03` で初めて声が裏返る）
- **シナリオ:** 閉店後、恋人（同じ店のバイト・21歳）のアパートへ（HPT-01）
- **相手呼び:** きみ
- **一人称:** 私
- **FP08(パイズリ):** △（胸は控えめ。HPT-16/17 では FP10(素股) か FP05 を推奨）
- **口調参照:** [プロフィール.md](./プロフィール.md)

## 執筆方針

- セリフは1〜4語が基本。感情の自己解説はしない
- 変化は地の文で見せる（眉・唇・耳の赤み・指先）
- 主導権は握りたがるが、奥を突かれると崩れる
- 中出し／外出しはルート別（外出し後に「抜かないで」を混ぜない）
