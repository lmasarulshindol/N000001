# HPT-09(二回戦)

1回目 `MN07(射精/中出しor外出し)` まで → **短い `AF01(余韻・呼吸を整える)` のみ** → 2回目も `MN01(挿入)`–`MN07(射精/中出しor外出し)`（インスタンスは `-R2` suffix 推奨）。

## 使用ノード

| 回 | 流れ |
|----|------|
| 1回目 | IN → FP → MN01(挿入)–MN07(射精/中出しor外出し) |
| 間 | AF01(余韻・呼吸を整える) のみ |
| 2回目 | MN01(挿入)–MN07(射精/中出しor外出し)（MN04(体位変更) は任意） |
| 終了 | AF01(余韻・呼吸を整える)–AF03(後始末・着衣), AF99(Hシーン終了→ストーリー再開) |

**インスタンスID例:** `BD-SCxx-MN03-R2`（2回目・MN03(テンポを上げる)）

```mermaid
flowchart TD
    IN00([IN00(Hシーン開始)]) --> IN01[IN01(場所・状況の提示)]
    IN01 --> IN02[IN02(キス・抱き寄せ)]
    IN02 --> IN03[IN03(衣服を乱す/脱衣開始)]
    IN03 --> FP01[FP01(胸・首筋への愛撫)]
    FP01 --> FP02[FP02(身体を撫でる)]
    FP02 --> FP03[FP03(下着をずらす/脱がす)]
    FP03 --> FP04[FP04(手指での愛撫)]
    FP04 --> FP05[FP05(口での愛撫)]
    FP05 --> FP06[FP06(感度・濡れの確認)]
    FP06 --> FP07[FP07(挿入準備・体位を整える)]
    FP07 --> MN00[MN00(生で挿入)]
    MN00 --> MN1A[MN01(挿入)・1回目]
    MN1A --> MN1B[MN02(ゆっくりした抽送)]

    AF02 --> AF03[AF03(後始末・着衣)]
    AF03 --> AF99([AF99(Hシーン終了→ストーリー再開)])
```
