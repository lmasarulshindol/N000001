## 執筆方針（改訂後）

- 状況説明・自己分析セリフを削る（「アプリで〜」「変ですよね」等）
- **喘ぎ・吐息・身体反応**で快楽を見せる（Show）
- 丁寧語は前半寄り。`MN03` 以降は崩す（「です」が消える／単語だけ）
- 中出し／外出しはルート別（外出し後に「抜かないで」を混ぜない）

## 使い方

1. シナリオ設計で HPT を選ぶ  
2. 対応する `HPT-xx_セリフ.md` をノード順に並べ、プロット・台本に貼る  
3. 中出し／外出しはルート別原稿（外出し後に「抜かないで」等の中出し前提語を混ぜない）
