## 共通前提

- **対象年齢:** **18歳（高校卒業後・成人）** または **19歳（大学生）**。在学中・制服の設定は使わない — [プロフィール.md](./プロフィール.md) 参照。セリフMDヘッダに期を明記
- **見た目・物腰:** 清楚系・柔らかい
- **核:** 性欲は人一倍強い（ギャップ）
- **シナリオ:** マッチングアプリで知り合った男性とホテル（HPT-01/04〜06）、合意の3P（HPT-02）、AV撮影での複数人（HPT-03）
- **相手呼び:** 文中ではほぼ呼ばない（喘ぎ優先）／必要時のみ「あなた」
- **一人称:** 私（後半は断片化しがち）
- **口調参照:** [プロフィール.md](./プロフィール.md)

## 執筆方針（改訂後）

- 状況説明・自己分析セリフを削る（「アプリで〜」「変ですよね」等）
- **喘ぎ・吐息・身体反応**で快楽を見せる（Show）
- 丁寧語は前半寄り。`MN03` 以降は崩す（「です」が消える／単語だけ）
- 中出し／外出しはルート別（外出し後に「抜かないで」を混ぜない）

## 使い方

1. シナリオ設計で HPT を選ぶ  
2. 対応する `HPT-xx_セリフ.md` をノード順に並べ、プロット・台本に貼る  
3. 中出し／外出しはルート別原稿（外出し後に「抜かないで」等の中出し前提語を混ぜない）
