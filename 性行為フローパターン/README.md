## シナリオへの当て方

```
{シナリオID} = 作品略号 + シナリオ番号（例: BD-HJ01）
{ノードID}   = マスタの IN/FP/MN/AF（拡張: IN10, FP08–10, AF10, AF11）
パターンID   = HPT-xx（進行の型）
```

- 複合例: **HPT-15 + 体部HPT-04**（BD-HJ01）
- 1シナリオで途中から別 HPT に切り替えない（例外: HPT-09/11 のラウンド繰り返し）

## VNフローテスト（HTML）

| ファイル | 用途 |
|---------|------|
| [flow-vn-test.html](./flow-vn-test.html) | ノベルゲー風 UI で HPT 完走テスト |
| [build_vn_data.py](./build_vn_data.py) | セリフ MD → `vn-data.js` 生成 |
| `vn-data.js` | 生成データ（HTML から読み込み） |

```powershell
$OutputEncoding = [System.Text.Encoding]::UTF8; [Console]::OutputEncoding = [System.Text.Encoding]::UTF8
cd "c:/Users/MasaruShindo/work2/999_その他/N000001/性行為フローパターン"
py -3 build_vn_data.py
py -3 -m http.server 8765
```

ブラウザで `http://localhost:8765/flow-vn-test.html` を開く（`file://` でも `vn-data.js` 同梱なら可）。  
**分岐（クリックで選択肢表示）**

| タイミング | 選択肢 |
|-----------|--------|
| **HPT-17** `FP03` 後 | FP08 / FP05 / FP09 / FP10 |
| **MN00**（挿入前） | **生固定**（選択肢なし）。`protection=raw`。セリフは `MN00` / `MN00:生` |
| **MN07**（本番フィニッシュ） | 中／外。**選択後は許可禁止**（行為 → 反応。キーはフラグ付き `MN07:中:生` 等） |

**フラグとキー解決**

| フラグ | 中に出す | 外に出す |
|--------|---------|---------|
| 生 (`raw` 固定) | `MN07:act:中:生` + `MN07:中:生` → AF `*:中:生` | `…:外:生` |
| **FIN**（口奉仕ルート） | 口に出す / 顔にかける / 胸にかける / 我慢する（ループ） |
| **FIN**（パイズリルート） | 胸に出す / 顔にかける / 我慢する（ループ） |

セリフ MD 更新後は `py -3 build_vn_data.py` を再実行。各 HPT は **HPT-01 をベースに不足ノードを補完**（HPT-04/15 参照行も自動取り込み）。

**セルフテスト（全ルート矛盾検査）**

```powershell
py -3 test_route_consistency.py
```

キャラ×HPT×中/外×奉仕分岐を網羅し、選択後の許可セリフ・中外矛盾を検出（生固定）。結果は `test_route_report.txt`。
